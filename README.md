## The entry

> I asked the office plant for career advice. It's the only one here still growing.

One line, 81 characters: a single sentence with a setup and a punchline,
built on one specific detail of office life, clear on first read.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```
